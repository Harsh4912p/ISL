## Adding More Signs

To add more signs to the database, edit `dataset_loader.py` and add entries to the `_generate_comprehensive_dataset()` method:

```python
{
    'name': 'SignName',
    'english_translation': 'English Translation',
    'hindi_translation': 'हिंदी अनुवाद',
    'description': 'Description of the sign gesture',
    'category': 'CategoryName',
    'difficulty_level': 'easy',  # or 'medium' or 'hard'
    'dataset_source': 'ISL'  # or 'ASL'
}
```

Then reload:
```bash
python load_signs.py
```

