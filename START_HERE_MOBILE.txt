    → Run: python init_db.py
    → Run: python load_signs.py
    → Run: python app.py

    → Edit: .env (change PORT=5001)
    → Restart: python app.py

Flutter won't run?
    → Run: flutter clean
    → Run: flutter pub get
    → Run: flutter run
